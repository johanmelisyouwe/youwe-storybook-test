# Agent instructions

This repo's design system comes from Figma. Before changing any component, story, token or style, read and follow **[FIGMA-SYNC.md](./FIGMA-SYNC.md)**. Section 0 of that file lists this repo's paths and commands.

- Figma is the source of truth. Do not hard-code design values or invent content; use `src/tokens/tokens.css` and the texts and images from Figma.
- `src/tokens/tokens.css` and `src/tokens/tokens.resolved.json` are generated by `npm run tokens`. Never edit them by hand.
- Component CSS goes in `@layer components`; typography uses the `.yw-*` classes.
- `figma-sync.json` records what has been synced. Update it whenever you change a component or template.
- Finish every change with `npm run typecheck` and `npm run check`.

Tool-specific rule files (`CLAUDE.md`, `.cursor/rules/*.mdc`, `.github/copilot-instructions.md`) contain only one line: "Follow AGENTS.md."
